# BPMF Apps Script 同步 — 家長部署步驟

一次性設定，之後兒童裝置不需再登入。

1. 開啟你要存資料的 Google 試算表（或新建一個）。
2. 選單「擴充功能 → Apps Script」。
3. 把 `Code.gs` 內容整份貼進編輯器，儲存。
4. 左側「專案設定 ⚙ → 指令碼屬性」新增一筆：
   - 屬性：`SECRET`
   - 值：與兒童 App「Apps Script 同步」分頁裡的 secret **完全相同**
     （建議在 App 按「產生 secret」後複製過來）。
5. 右上「部署 → 新增部署作業 → 類型選『網頁應用程式』」：
   - 執行身分：**我**
   - 誰可以存取：**任何人**
6. 複製產生的「網頁應用程式 URL」，貼回兒童 App 的「Apps Script 同步」分頁的 URL 欄。
7. 在 App 完成一次故事，回試算表確認出現以小孩名為名的分頁與資料列。

> 更新 `Code.gs` 後要「管理部署作業 → 編輯 → 版本選『新版本』」才會生效。
> secret 若外洩，重新產生並同時更新 App 與指令碼屬性即可。
